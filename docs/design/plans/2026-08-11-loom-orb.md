# LOOM Orb + Living UI (Phase 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make LOOM look and feel *alive* — a breathing, oracle-light **orb** as the presence's face (react-three-fiber, GLSL displacement, fresnel, bloom), and a **living dashboard** (glass depth, spring motion, ambient light that follows the orb's mood) — with graceful tiering so it never breaks on weak WebGL.

**Architecture:** A pure **orb state module** maps LOOM's lifecycle (idle / listening / thinking / building / speaking / offline) to visual targets (color, amplitude, speed) with lerped transitions — unit-testable with zero WebGL. The **WebGL orb** is a custom ShaderMaterial on an icosphere: two-layer simplex fBm vertex displacement (slow breath + fine shimmer), fresnel rim + iridescent tint in the fragment shader, HDR-thresholded bloom via postprocessing; uniforms driven each frame from the state module + a shared `audioLevel` ref (voice-ready for phase 5). Capability detection picks tiers: full WebGL → reduced (no post) → a **2D CSS/canvas fallback orb** that shares the same state module. The **living shell** rebuilds App's layout: orb hero, glass panels, framer-motion springs, an ambient radial glow tinted by orb state, cursor spotlight, film grain — honoring `prefers-reduced-motion`. Companion turn lifecycle and fleet health drive the orb.

**Tech Stack:** three, @react-three/fiber, @react-three/postprocessing, framer-motion (new deps); existing React/TS/vitest.

## Global Constraints

- Fully offline (all deps bundled; no CDN/fonts/network). No emojis anywhere.
- Brand: navy `#060b18` base; cyan `#22d3ee` accent. State colors from tokens: listen `#0a84ff`, think `#a78bfa`, speak `#10b981`, offline dim slate; idle = cyan. NO yellow.
- The orb must NEVER be fully static while healthy — idle breathes (slow ~4s cycle). All state changes lerp (0.05–0.15/frame), never snap.
- Tiering: WebGL2 detect → full (displacement + bloom); fallback tier 0 = 2D orb (CSS radial gradients + canvas rings) with the SAME state module. `prefers-reduced-motion` → freeze idle motion, keep state colors, no springs.
- jsdom cannot run WebGL: all state/mapping logic lives in pure modules with full vitest coverage; the r3f component itself is excluded from jsdom rendering via capability detection (tests force tier 0).
- Perf: single canvas, icosahedron detail ≤ 24, no per-frame allocations in useFrame, dispose on unmount.
- DRY, YAGNI, TDD, frequent commits.

### Task 1: Pure orb state + capability + audio modules

**Files:** Create `src/lib/orb/state.ts`, `capability.ts`, `audioLevel.ts` + tests.

**Interfaces (exact):**
- `export type OrbMood = "idle" | "listening" | "thinking" | "building" | "speaking" | "offline"`
- `export type OrbTargets = { color: string; amp: number; speed: number; glow: number }`
- `export const MOOD_TARGETS: Record<OrbMood, OrbTargets>` — idle `{#22d3ee, 0.22, 0.35, 0.55}`, listening `{#0a84ff, 0.34, 0.7, 0.8}`, thinking `{#a78bfa, 0.3, 1.0, 0.75}`, building `{#7dd3fc, 0.38, 1.2, 0.9}`, speaking `{#10b981, 0.36, 0.8, 0.85}`, offline `{#5f6f8c, 0.08, 0.12, 0.25}`.
- `export type OrbState = { color: [number, number, number]; amp: number; speed: number; glow: number }`
- `export function hexToRgb(hex: string): [number, number, number]` (0..1 floats)
- `export function stepOrbState(cur: OrbState, mood: OrbMood, dt: number, audioLevel = 0): OrbState` — lerps each channel toward MOOD_TARGETS[mood] with rate `1 - Math.exp(-dt * 4)` (frame-rate independent); amp target is boosted `+ audioLevel * 0.5` (clamped ≤ 0.9); returns a NEW object.
- `export function breath(t: number): number` — `0.5 + 0.5 * Math.sin(t * (2 * Math.PI / 4))` (4s cycle).
- capability.ts: `export type OrbTier = "gl" | "flat"`; `export function detectTier(env?: { webgl2?: boolean; reducedMotion?: boolean; forceFlat?: boolean }): { tier: OrbTier; reducedMotion: boolean }` — injectable for tests; real detection: `!!document.createElement("canvas").getContext("webgl2")`, `matchMedia("(prefers-reduced-motion: reduce)").matches`, and `localStorage.getItem("loom.orb") === "flat"` forces flat.
- audioLevel.ts: `export const audioLevel = { current: 0 }`; `export function envelope(prev: number, sample: number, attack = 0.65, decay = 0.12): number` — fast attack, slow decay (AgentZeus-proven).

**Steps:** TDD — tests: MOOD_TARGETS completeness (all 6 moods, no yellow hexes); hexToRgb correctness (`#22d3ee` → ~[0.133,0.827,0.933]); stepOrbState converges toward target over repeated steps, is frame-rate independent-ish (two 0.008 steps ≈ one 0.016 step within tolerance), never mutates input, audio boosts amp target but clamps; breath oscillates in [0,1] with period 4; detectTier matrix (webgl2 false → flat; forceFlat → flat; reducedMotion propagates); envelope attack>decay behavior. RED → implement → GREEN → `npm test` → commit `feat(orb): pure state, capability tiers, audio envelope`.

### Task 2: The WebGL orb (shaders + r3f + bloom) and the 2D fallback

**Files:** `npm i three @react-three/fiber @react-three/postprocessing` + `npm i -D @types/three`. Create `src/components/orb/shaders.ts`, `OrbGL.tsx`, `Orb2D.tsx`, `Orb.tsx` + `orb.test.tsx`.

**shaders.ts (exported strings, unit-tested for key features):**
- `VERT`: uniforms `uTime, uAmp, uSpeed, uBreath`; a compact 3D simplex noise implementation (standard Ashima `snoise` — include it verbatim in the string); displacement = `snoise(normal * 1.6 + uTime * uSpeed * 0.25) * 0.6 + snoise(normal * 4.0 + uTime * uSpeed * 0.6) * 0.25`, scaled by `uAmp * (0.75 + 0.25 * uBreath)`; displace along normal; pass `vDisp`, `vNormal`, `vView` (view dir) varyings.
- `FRAG`: uniforms `uColor (vec3), uGlow`; fresnel `pow(1.0 - max(dot(normalize(vNormal), normalize(vView)), 0.0), 3.0)`; base = mix(deep navy `vec3(0.024,0.043,0.094)`, uColor, `vDisp*0.5+0.5` * 0.85); iridescent shift = tiny hue tilt via mixing uColor with `uColor.gbr` by `fresnel*0.35`; final `base + (uColor * fresnel * uGlow * 1.6)`; push rim above 1.0 for bloom threshold.
- `OrbGL.tsx`: `<Canvas dpr={[1, 2]} gl={{ antialias: true, alpha: true }}>` containing an `<icosahedronGeometry args={[1.15, 24]}/>` + `shaderMaterial` with the uniforms; `useFrame((s, dt) => { ... stepOrbState via a ref, set uniforms, uTime += dt, uBreath = reducedMotion ? 0.5 : breath(t) ... })` — NO allocations in the loop (preallocate a THREE.Color / reuse refs); `<EffectComposer><Bloom luminanceThreshold={1} intensity={1.4} mipmapBlur/></EffectComposer>`; props `{ mood: OrbMood; reducedMotion: boolean; size?: number }`; dispose handled by r3f unmount.
- `Orb2D.tsx`: same props; a layered CSS orb — radial-gradient core (state color → navy), a soft outer glow (box-shadow, animated scale when not reducedMotion via CSS keyframes 4s), thin rim border; color transitions via CSS `transition: 1s`. Driven by MOOD_TARGETS[mood].color/glow directly. `data-testid="orb-2d"`.
- `Orb.tsx`: `detectTier()` once (state) → render OrbGL or Orb2D; catches OrbGL runtime errors with an error boundary that PERMANENTLY falls back to Orb2D (sets `localStorage["loom.orb"]="flat"`), so a driver crash never recurs. `data-testid="orb"`.

**Tests (jsdom, force flat):** Orb renders Orb2D when detectTier → flat; mood prop changes the 2D orb's color style (idle cyan vs offline slate); shaders.ts strings contain `snoise`, `uAmp`, `uBreath`, fresnel pow, and FRAG pushes rim >1.0 (contains `* 1.6`); error-boundary fallback: a child that throws → Orb2D rendered + localStorage flag set (simulate by rendering Orb with a stubbed GL component that throws — export an internal `__setGLComponentForTest` hook or accept a `glComponent` prop default OrbGL).

**Steps:** deps install → TDD → implement → `npm run check` green → commit `feat(orb): oracle-light WebGL orb with breathing displacement + bloom, tiered 2D fallback`.
