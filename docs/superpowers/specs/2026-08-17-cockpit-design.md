# The Sovereign Cockpit — Merger Design (Phase 9, Stage 1)

**Decision record (2026-08-17, user-approved):** LOOM becomes the Sovereign Cockpit. The portfolio merges INTO LOOM rather than any project being rebuilt: AUSPEX (living globe), AgentZeus (constellation/salience/ledger — later stages), Flexport terminal decks (later), EMBER failsafe (later), AGORA/KEEL/PRISM/SIGNET (deferred decks). Builder gains a cloud override: local Ollama default, Claude API opt-in. First deck: AUSPEX globe.

North-star: `~/Downloads/AgentZeus/VISION-SOVEREIGN-COCKPIT.md` ("JARVIS for the planet") — the orb speaks, the globe turns to what it's talking about, agents light up as they work, and the machine builds its own instruments on request. This stage delivers the first fusion: **orb + living world + voice command of the world + a builder that can actually build.**

## Stage-1 scope (this phase)

1. **Deck architecture.** The Shell gains a deck layer: full-bleed surfaces that render BEHIND the three-zone UI (below orb band and chat, above the ambient Field). One deck active at a time; `deck: "void" | "globe"` for now. The void deck is the current ambient look (default). Deck state in kernel store (`cockpit.deck`); switching via UI control (top bar) AND voice/companion intent ("show the globe", "hide the globe"). The orb NEVER moves — decks change the world behind it. Chat panel (Zone C) gains a translucency/compact treatment while a deck is active so the world stays visible (chat collapses to a lower-third strip; expandable).
2. **AUSPEX globe deck.** Embedded as an iframe deck loading a BUNDLED copy of AUSPEX's static app (`decks/auspex/` copied from `~/Downloads/AUSPEX`: index.html, js/, css/, assets/, data/, src/ — NO node_modules/api/worker; snapshot.json fetched from the deployed AUSPEX URL with bundled fallback copy). Its live browser-side feeds keep working as-is (AUSPEX public Supabase anon reads, USGS; keyed feeds silently degrade — AUSPEX already does graceful fallback). A small ADAPTER file added to the bundled copy (not upstream) listens for `postMessage` commands from the LOOM shell and drives AUSPEX's existing bridge-command vocabulary (same verbs its AgentZeus bridge poller executes: set_cat / toggle_overlay / reset_view / set_spin / open_page etc. — implementer reads `js/main.js` bridge executor for the exact set). The existing localhost:3000 bridge poller stays OFF (it's opt-in via localStorage already).
3. **Voice/companion command of the globe.** The compiler's intent layer gains a `deck_command` intent (rule-first): "show/open the globe", "hide the globe", "show military/finance/climate news", "show vessels/ships", "stop spinning", "reset the view". Routes to a deck-command dispatcher that posts the mapped bridge command into the iframe. Unknown deck phrasing falls through to the existing model classifier with `deck_command` added to its few-shot label set. Companion speaks a one-line confirmation; orb mood pulses on deck commands.
4. **Builder cloud override.** New settings key `model.cloudBuilder` ("off" default | "anthropic"); Settings → Models page gains a "Cloud builder" section: enable toggle + API key field (stored in kernel store, never in organ-readable storage; masked in UI) + per-build banner showing which brain built it. When enabled, buildOrgan's `builder`-role chats route to Anthropic Messages API (model `claude-opus-4-8`) via a Rust command `cloud_chat` (key never enters the webview after save — Rust reads it from a Tauri-side store file). Local fleet remains the default and the fallback on any cloud error. Experience records gain `brain: "local" | "cloud"`.
5. **Non-goals this stage:** constellation port, salience engine, Bloomberg terminal deck, EMBER deck, AgentZeus agent roster, AUSPEX code changes upstream, multi-deck simultaneous rendering, mobile.

## Architecture notes
- Deck layer z-order: Field (1) < deck (2-3) < orb band (10) < plane (100) < dock (1000). The orb band's `mixBlendMode: screen` composites the orb's light OVER the globe — verified concept: screen blend adds light onto whatever is behind, which is exactly the oracle-over-the-world look. Ambient Field/Threads stay on in void deck; in globe deck the Field dims (opacity ~0.35) to let the world read.
- The iframe gets `sandbox` minimal relaxations it genuinely needs (allow-scripts allow-same-origin — required for its Supabase fetches + localStorage; document why in code) and pointerEvents auto only when deck is active AND user toggles "interact" mode (a top-bar button; otherwise clicks pass to LOOM surfaces — prevents the globe stealing orb/PTT clicks). Keyboard PTT (Space) keeps working while interacting with the globe iframe? — Space is captured by the shell's window listener; iframe focus steals it — acceptable stage-1 limitation, documented.
- Anthropic call shape (Rust `cloud_chat`): POST https://api.anthropic.com/v1/messages, headers x-api-key + anthropic-version: 2023-06-01, body {model: "claude-opus-4-8", max_tokens: 8192, system, messages}. Adaptive thinking omitted (builder prompts are single-shot codegen; keep simple stage-1). Timeout 120s, one retry, then local fallback.
- Repo: this stays in the LOOM repo (it IS the cockpit now). AUSPEX bundle is a committed snapshot copy with a README noting provenance + refresh script (`scripts/refresh-auspex-deck.sh` rsyncs from ~/Downloads/AUSPEX excluding node_modules/api/worker/keys.local.js).
