# Phase 19 Implementation Plan — Vigor

> **For agentic workers:** checkbox steps. Spec: `docs/superpowers/specs/2026-08-22-vigor-design.md` (authoritative).

**Goal:** organs get six real powers — market, watch, timeline, voice, notify, pulse — declared in the manifest, approved on the permission card, budgeted, revocable, sandbox-mocked; the builder's prompts learn them; one powered selftest case proves the loop.

**Tech stack:** existing only.

## Global constraints
- Every power call goes through the existing `need()` grant seam; undeclared/ungranted → the existing permission error, never a crash.
- Budgets enforced in api.ts (pure, testable): market ≤30 req/min, voice ≤1/30s, notify ≤6/h — per organ; throttled = calm error + dim THROTTLED chip on the organ window.
- Tokens only; BRAND voice for all copy. Gates: `npm run check` green per task.

### Task 1: The powers (runtime)

**Files:** `src/lib/organs/api.ts` (+ tests): extend `LoomApi` with `market` (thin async wrappers over core.ts market fns), `watch` (`top(n)` from the watch runtime's ranked items, `list()` watchlist), `timeline` (`log(n)` via timelineLog), `voice` (`say(text)` → existing TTS speak path, 300-char cap), `notify(title, body)` → dispatches `loom-notify` event, `pulse.every(ms, fn)` (min 30_000ms, max 4 per organ, returns cancel; registry keyed by organ id, cleared on unmount/delete — wire into the organ window lifecycle + purgeOrganStorage). Budget module `src/lib/organs/budgets.ts` (pure token-bucket, tested, injectable clock). Grants: extend the existing grant store to per-power tokens; manifest schema gains `powers?: string[]` (validate subset of the six in the manifest guard — find it in the loom validate path). Permission card (grep the approval card component): renders requested powers in plain language; approval grants exactly those. Revocation: organ window gains a POWERS row in its existing chrome/menu surface (list + revoke toggle → clears token live). Notify surface: `src/components/chrome/Notices.tsx` (+ test) — glass toast stack top-right under the top bar, calm, dismiss ✕, auto-dim after 12s (reduced-motion: no animation), listens on `loom-notify`, caps 3 visible + count chip.
**Sandbox:** the gate sandbox (src/lib/loom/sandbox.ts + harness) mocks all six deterministically (canned market fixtures, say → recorded, notify → recorded, pulse → immediate-fire-once test hook, watch/timeline → canned rows); generated tests can assert against the mocks.
