# Phase 23 — Rebirth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A packaged LOOM that carries its own genome, threads the loom once from the machine's tools, and thereafter — offline — edits, validates, weaves a new binary, swaps itself, relaunches, and heals a bad birth through the previous generation acting as warden.

**Architecture:** Five new PROTECTED Rust modules under `src-tauri/src/` (`loomhome.rs` identity+paths, `threads.rs` tool discovery+ceremony, `generations.rs` ledger, `platform.rs` swap plan+execution, `reweave.rs` build job, `warden.rs` birth guard), argv dispatch at the top of `lib.rs`, extensions to `exec.rs` (envs) and `kernel.rs` (packaged source root, recorded tools, node_modules symlink, `--offline`, `armedBy: "reweave"`). TS side: two protected orchestration modules (`reweave.ts`, `generations.ts`), a reweave card, packaged framing on the diff card, companion rules, Shuttle entries, Settings LOOM section, Tapestry generation strand.

**Tech Stack:** Tauri v2 · Rust (std::process, git2 for read-only lookups, `git` CLI through `exec.rs` for mutations) · React 19 / TS / Vite · vitest · cargo test · Node 20+ for scripts.

**Spec:** `docs/superpowers/specs/2026-09-02-rebirth-design.md` — read it first; every task argues from it.

## Global Constraints

- `npm run check` (vitest + `cargo test`) green at every commit. `npx tsc --noEmit` clean.
- Copy law (`docs/BRAND.md`): calm lowercase sentences, uppercase-mono chrome labels, no exclamation marks, failure = fact — hinge — remedy.
- Tokens only; no raw hex outside `public/brand/`.
- Every spawn goes through `exec.rs` (`run_checked` / `run_checked_env`): fixed argv, canonicalized cwd inside an allowed root, no shell. Env pairs are composed from constants and LOOM-owned paths only.
- Network: reweave and validation always pass `--offline`; threading is the only step allowed to touch the network and says so.
- Never weaken the protected set. New safety files are added to `PROTECTED_RUST` / `PROTECTED` and to the enumerated test in the same task that creates them.
- Never execute untrusted generated tests (`cargo test --no-run` stays).
- Errors use the existing `LoomError { Http, Timeout, Parse, Git, NotFound }`. Add `Unsupported(String)` in Task 1 (serialized kind `"unsupported"`).

### Task 9: `reweave.rs` — the build job (assets · core · stage · swap · relaunch)

**Files:**
- Create: `src-tauri/src/reweave.rs`
- Modify: `src-tauri/src/lib.rs` (register `reweave::reweave_start`, `reweave::reweave_cancel`, `reweave::reweave_state`, `reweave::generations_return`), `src-tauri/src/kernel.rs` (protect; `kernel_apply` in packaged mode leaves the sentinel `applied`… **no** — a source apply in packaged mode writes NO sentinel, because nothing boots until a reweave; document this in a comment and a test `packaged_apply_does_not_arm_the_sentinel`), `src/lib/core.ts` (`reweaveStart`, `reweaveCancel`, `reweaveState`, `generationsReturn`, `ReweaveState` type)

**Interfaces:**
- `#[derive(Serialize, Deserialize, Clone)] #[serde(rename_all="camelCase")] pub struct ReweaveState { pub stage: String /* idle|assets|core|stage|swap|relaunch|done|failed|cancelled */, pub target_sha: Option<String>, pub started_at: Option<String>, pub elapsed_ms: u64, pub tail: Vec<String> /* ≤ 400 */, pub outcome: Option<String>, pub cancellable: bool, pub mode: Mode }` — persisted to `reweave.json` after every change; emitted as `loom-reweave`.
- `#[tauri::command] pub fn reweave_start(app, force: bool) -> Result<(), LoomError>`: preconditions per spec (threaded; nothing in flight — shares a `static JOB` with threads via a `jobs::Slot` helper you add to `exec.rs`: `pub struct Slot(Mutex<Option<u32 /*pgid*/>>)` with `try_take/release/kill`; HEAD ≠ current or `force`). Spawns the job thread.
- Job: `assets` → `[npm, run, build]` cwd source (10 min, streamed). `core` → `[cargo, build, --release, --offline]` cwd `source/src-tauri`, envs target+offline (30 min, streamed). `stage` → `generations::record(home, head_sha, target/release/loom, reason)` then `Codesign` the generation exe. Dev mode → set `outcome: "built — in dev, restart tauri dev to load the core"`, stage `done`, return.
