**Goal:** LOOM safely edits its own TypeScript kernel behind five walls — isolation, real tsc+vitest validation, owner diff-approval, commit-to-source-repo, recovery boot — with a hard self-protection invariant (it cannot edit its own safety machinery). Dev-mode, TS-only, hot-reload apply.

**Tech stack:** existing only (git2, std::process::Command, reqwest already present). No new deps.

## Global constraints
- **The five walls are mandatory and ordered** (spec §"five walls"). No path skips a wall. The live tree is never written before validation passes AND the owner approves.
- **Self-protection invariant** (spec): positive whitelist `src/**/*.ts(x)` minus the carved-out protected set; enforced in Rust before isolation; tested with a "tries to edit the guard → refused" case.
- **Hardened spawn**: fixed argv, no shell, cwd canonicalized + asserted under the source repo, timeout, process-group kill (unix) — mirror the old agora.rs discipline.
- **Sovereignty**: source repo path resolved locally (dev cwd / setting), asserted to be a git repo; everything local; no telemetry.
- Tokens only; BRAND voice; honest "this edits LOOM itself" framing. Gates: `npm run check` green per task.

### Task 1: The safety core (Rust) — exec + kernel + recovery

**Files:**
- `src-tauri/src/exec.rs` (new, + tests): `run_checked(argv: &[&str], cwd: &Path, timeout: Duration) -> Result<ExecOut{code,stdout,stderr}, LoomError>` — fixed argv (no user string in argv), cwd `canonicalize()`d and asserted `starts_with` the source-repo root, `Stdio::piped()`, `process_group(0)` (`#[cfg(unix)]`) + group-kill on timeout/drop, stdout/stderr ring-capped. Tests: exit 0, non-zero, timeout kills the tree, cwd-escape refused.
- `src-tauri/src/kernel.rs` (new, + tests) + register in lib.rs. Source-repo root resolver (dev cwd or a `kernel.sourceRepo` setting; assert it's a git work dir). Positive whitelist + PROTECTED carve-out list (spec §self-protection) → `is_editable(rel_path) -> bool`. Commands:
  - `kernel_editable() -> {root, protected: string[]}` (meta for the UI/prompt).
  - `kernel_propose(edits: Vec<KernelEdit{path, search, replace}>) -> Result<{worktreeId, diff}>`: reject any non-editable path (typed error) → `git worktree add` a temp worktree at HEAD → apply each SEARCH/REPLACE (exact unique match, like edits.ts) → produce unified diff (git2 diff or `git diff`) → return. Never touches live tree.
  - `kernel_validate(worktreeId) -> {ok, stage: "tsc"|"vitest", output}`: run `npx tsc --noEmit` then a targeted `npx vitest run <files+tests>` via exec in the worktree; first failure returns stage+output.
  - `kernel_apply(worktreeId, message) -> {sha, prevSha}`: record prevSha=HEAD → apply the worktree's patch to the LIVE tree (checkout/merge the change) → `git commit` on the source repo with `self: <message>` → write sentinel `{prevSha, appliedSha:sha, status:"pending"}` to app-data → remove worktree.
  - `kernel_rollback(sha)`: hard-reset source repo to sha.
  - `kernel_boot_ok()`: set sentinel status "ok" (or delete).
  - `kernel_boot_check() -> {rolledBackTo?: sha}`: if sentinel status=="pending" → rollback to prevSha, clear sentinel, return the sha (the shell shows a recovery notice); else noop. Call this early in the Tauri setup (lib.rs) so a broken edit is undone before/at boot.
  - worktree cleanup on abort/error (no orphan worktrees); `git worktree prune` safety.
  Tests (tempdir git repos): whitelist accept/reject + self-protection refusal; propose creates worktree + diff, live tree unchanged; apply commits to source repo + writes sentinel + records prevSha; rollback resets; boot_check decision table (pending→rollback, ok→noop, absent→noop); worktree cleanup. Skip-guarded integration test: real `npx tsc --noEmit` on a passing fixture (ok) and a type-error fixture (fail) in a temp worktree — proves the validation wall actually catches breakage (guard: skip if npx/tsc unavailable, like the existing ignored live test).
- `src/lib/core.ts`: typed wrappers for all kernel commands (+ tests).

- [ ] exec tests → exec.rs → kernel tests → kernel.rs + lib.rs boot_check wiring → core wrappers → skip-guarded tsc integration test → green → commit `feat(selfhood): the safety core — isolate, validate, commit, recover`.
