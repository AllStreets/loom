# Phase 17 Implementation Plan — Depth

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps. Spec: `docs/superpowers/specs/2026-08-22-depth-design.md` (authoritative).

**Goal:** the Terminal and AGORA decks stop being empty. Root-cause fix (Yahoo UA), a typed Rust market engine over keyless sources (Yahoo chart, Coinbase Exchange, Frankfurter), Terminal depth (watchlist, detail panel, crypto/FX strips, per-panel honesty), and AGORA's native floor (order book + trades).

**Tech stack:** existing only (reqwest, serde already present). No keys, no new JS deps.

## Global constraints
- Sovereignty: desktop traffic only through the Rust engine; hosts allowlisted (`query1/query2.finance.yahoo.com`, `api.exchange.coinbase.com`, `api.frankfurter.dev`); typed commands, symbol regex validation, no arbitrary URLs. Browser dev: Coinbase/Frankfurter direct (CORS-open), Yahoo via existing corsproxy path only.
- Design language + screenshot gate bind UI. Tokens only. Empty panels must state why.
- Gates: `npm run check` fully green per task.

### Task 1: The market engine

**Files:** `src-tauri/src/market.rs` (new; `quotes.rs` folded in or delegating — keep the `quote_fetch` command name working if the frontend uses it, else migrate call sites), registered in lib.rs. Commands per spec: `market_chart`, `market_crypto`, `market_book`, `market_trades`, `market_fx`. All: browser UA header (the 429 root fix — verified live: Yahoo 429s reqwest's default UA), 10s timeout, typed `LoomError`s, symbol/product regex (`^[A-Z0-9.^=-]{1,12}$` equities incl. ^VIX/GC=F style; `^[A-Z]{2,6}-USD$` products; `^[A-Z]{3}$` fx codes). Yahoo: query2 retry on 429/5xx. Tests: validation rejects/accepts, response parsing from fixture JSON (no network in tests), ring of pure helpers. TS side: `src/lib/core.ts` wrappers + types; `src/lib/terminal/quotes.ts` browser-path additions (Coinbase/Frankfurter direct fetch with AbortSignal timeout; Yahoo dev path unchanged) — same shape both paths, tested.

- [ ] rust tests → market.rs + lib.rs → core.ts wrappers → browser adapters → green → commit `feat(depth): the market engine — typed keyless sources, the 429 root cause dead`.

### Task 2: Terminal depth

**Files:** `src/components/decks/TerminalDeck.tsx` (+ test), `src/lib/terminal/quotes.ts` (symbol config), `src/lib/voice/settings.ts` (`terminal.symbols` — validated comma list, defaults = current list). UI: (a) movers table gains inline add (input + ADD, ticker validated) and hover-reveal remove per row; watchlist drives the poller live. (b) Click any index card / mover row → detail overlay panel (glass, Esc/click-out closes, `data-testid`): large intraday area chart from the chart data (SVG, axis ticks, day range), OHLC/prev-close/volume/delta readouts. (c) CRYPTO strip: BTC/ETH/SOL via `market_crypto`, spot + 24h delta, poll 30s. (d) FX strip: EUR/GBP/JPY vs USD via `market_fx`, labeled "daily" honestly, poll 10min. (e) Health chrome: EQUITIES/CRYPTO/FX dots (fresh <2× poll = go, stale = warn + age, error = danger + calm copy); every panel has explicit empty/error states. Poller lifecycle: all polls start on mount/stop on unmount, pause when document hidden (existing pattern).

- [ ] tests → settings → panels (watchlist → detail → crypto → fx → health) → screenshots (populated, detail open, error state via mocked failure) → green → commit `feat(depth): the terminal deepens — your tape, real depth, honest panels`.

### Task 3: AGORA's floor

**Files:** `src/components/decks/AgoraDeck.tsx` (+ test), `src/lib/voice/settings.ts` (`deck.agora.product`, default "BTC-USD", whitelist BTC-USD/ETH-USD/SOL-USD). When probe says local AGORA unreachable → render THE FLOOR instead of the lone card: (a) product chips (persisted, switch restarts polls); (b) order-book ladder via `market_book` depth ~12/side, 2s poll: price/size/cumulative bars (size bars as background fills, accent bids / danger asks), mid + spread (abs + bps) center readout; (c) trades tape via `market_trades`, ~20 rows, side-tinted, newest top, 3s poll; (d) the launch card compresses to a top strip (status line + START/RETRY + settings hint + last log lines while igniting — all existing states preserved, just re-laid); (e) reachable → iframe exactly as today (floor unmounts, polls stop). Errors: calm per-panel copy ("the exchange feed is dark — retrying"), never deck-blank. All polls lifecycle-bound + document-hidden pause; no leaks (fake-timer tested).

- [ ] tests → setting → floor (ladder → tape → chips → strip re-lay) → screenshots (floor live, igniting strip over floor, iframe unchanged) → green → commit `feat(depth): the exchange gets a floor — the deck is never empty again`.
